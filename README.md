# Weather Dashboard (Погодний дашборд)

Навчальний проєкт для курсу клієнтського програмування.

## Звіт з безпеки (Security Audit)

- **XSS Вразливості:** Вразливість `innerHTML` при виведенні назви міста була виявлена та усунена шляхом екранування даних за допомогою кастомної функції `escapeHtml()`.
- **Локальні сховища:** В `localStorage` та `IndexedDB` зберігаються виключно безпечні дані (геокоординати, температура, імена міст). Жодних секретних токенів чи паролів на клієнті не зберігається.
- **HTTPS:** Застосунок готовий до деплою на платформи з підтримкою HTTPS (напр. GitHub Pages).
